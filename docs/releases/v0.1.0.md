# DSH-R v0.1.0

DSH-R 的首个独立发布版本，基于 DSH-X `v0.1.26-rc.4`。

## 主要功能

- 保留 DSH-X 的本机启动项、多实例、版本、Profile、插件、整合包、MCP、技能、恢复与日志管理。
- 新增 Windows 控制端对远程 Linux DSH 的 SSH 管理。
- 支持远程版本安装、删除、替换和依赖优化。
- 支持远程 Profile、配置、插件、整合包、MCP、技能、恢复档、凭据状态和日志管理。
- 支持远程只读文件浏览、受限预览和官方拖拽上传链路。
- 内置远程完整 PTY Shell。
- 远端 DSH 保持回环监听，由 reverse-forward 暴露到 VPN / 局域网地址。
- 远程 DSH 页面进入 DSH-X 内部标签页。
- 适配 Linux AppImage / deb、XDG 目录和桌面集成。
- Windows 安装器支持安全退出、残缺旧安装修复、离线核心替换，并默认安装到 `D:\dsh`。

## 边界

- 远程控制端主要面向 Windows，远端目标为 Linux x64 / arm64。
- 不保存 SSH 密码；需要密钥、ssh-agent 或 OpenSSH 配置。
- 远程插件桌面 API 与 Windows 系统通知尚未桥接。
- 远程文件面板为只读浏览与受限预览，不支持任意路径写入或删除。
- 拖拽上传、文件树、右侧栏预览和路径点击依赖 DSH 官方插件。
- reverse-forward 仅支持 HTTP / WebSocket。
